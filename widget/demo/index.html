Support widget — test page

A deliberately plain page whose only job is to host the widget so it can be verified. The blue bubble is bottom-right. Everything the widget shows — branding, categories, suggestions, which tiles appear — comes from server-side product config, not from this page.

Identity (SSO)

In production your backend mints a short-lived JWT and passes it as data-identity-token. This page calls the gateway's dev-only minting endpoint instead, so the SSO path can be exercised without a backend.

Not signed in — the widget will greet you anonymously.
